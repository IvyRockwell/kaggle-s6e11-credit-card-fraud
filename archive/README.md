# Archive

Historical experiment scripts, kept for provenance:

- `v01`–`v16`: feature-engineering experiments under the protocol frozen at v02; each script documents one feature change.
- `fe_common.py`: shared runner used by v09–v16.
- `member_cache.py`: OOF caching used by the seed-average experiment.
- `positive_control_sensitivity.py`, `shap_interaction_screen.py`: diagnostics.

These scripts are not part of the final pipeline and may reference files that are no longer present.
